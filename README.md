UDP Server & Client App

It's an Android setup for testing UDP connections between a server and a client.

## What's inside
There are two separate Android projects in this repo:
* **Server_UDP:** The server-side app[cite: 3]. 
* **Clint_UDP:** The client-side app[cite: 3].

Both are built natively for Android and use Gradle with Kotlin scripts (`build.gradle.kts`) for the build system[cite: 3]. 

## How to run it
If you actually want to test it out:
1. Clone the repo.
2. Open either the `Server_UDP` or `Clint_UDP` folder in Android Studio[cite: 3]. You'll need to run both at the same time on different emulators or phones to test the connection.
